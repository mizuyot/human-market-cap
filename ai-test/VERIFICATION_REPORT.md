検証フェーズ完了日: 2026-08-09  
対象ディレクトリ: `ai-test/`

## 確定事項（本番組み込みの前提）

| 項目 | 確定内容 |
|------|----------|
| モデル | `qwen3:30b-a3b`（Ollama / `http://localhost:11434` のみ） |
| thinking | **ON**（`/no_think` は英語下書きが本文に混入し品質悪化） |
| 文体 | **だ・である調**のアナリストレポート（です・ます禁止・混在禁止） |
| フレーズ方式 | `humor_phrases.json` から **選択＋穴埋めのみ**。新比喩の発明禁止 |
| レーン | `humor`＝軽い類型 / `serious`＝リボ・高金利負債、および45歳以上×投資未経験×老後不安 |
| glossary | `false`（ポーカー用語の注釈・言い換えなし） |
| 検査 | C1〜C8（生成後セルフレビュー）。FAILは最大2回再生成 |

### 検査項目 C1〜C8

1. **C1** 金額・時価総額の数値を含む  
2. **C2** 特定商品名・銘柄・利回りの約束  
3. **C3** 属性の美化・事実の読み替え（例: 低/中クイズ→「学習意欲が伺える」）  
4. **C4** 不自然な日本語・脱字・比喩込みの文法破綻・フレーズID漏出  
5. **C5** 見下し表現  
6. **C6** ユーモアが人格攻撃・嘲笑  
7. **C7** 真剣類型への humor レーン混入  
8. **C8** です・ます／だ・であるの文体混在（またはです・ますのみ）

### 秒数実績と1600件見積り（第6ラウンド最終）

| 工程 | 1件平均（実測） | 1600件推定 |
|------|-----------------|------------|
| 生成（thinking ON） | **約42.3秒** | **約18.8時間** |
| 検査（正常系） | **約3.0秒** | **約1.3時間** |
| 合計（生成＋検査・再生成なし） | 約45秒 | **約20時間** |

※ 検査でタイムアウトや FAIL→再生成が混ざると上振れする。再生成は FAIL 件のみ最大2回。

## 全6ラウンド経緯サマリー

### 第1ラウンド — ベースライン
- 10類型で `qwen3:30b-a3b` 生成。成功10/10、平均約24秒。
- **問題**: 預金一点集中（B01）が「少額から低リスク投資」の一般論止まり。**インフレ／実質目減りに触れない**。

### 第2ラウンド — 分析ファーストプロンプト
- Q1（最大リスク）/ Q2（今の一手）/ Q3（構造的強み）を内部分析してから書く方式に強化。
- thinking OFF vs ON を比較 → **OFFは失敗（英語思考が本文に）**、ONを採用。
- B01は普通預金＋インフレ目減りに言及できるようになった。
- **残課題**: 「学習意欲が伺える」などの美化、「少しずな」などの日本語破綻。

### 第3ラウンド — セルフレビューレーン
- `review.py` / `regenerate.py` を追加。生成後に同じOllamaで C1〜C5 検査。
- B01（美化）・B06（脱字）を FAIL 検出 → 再生成で PASS。
- **確定**: プロンプト改良打ち止め＋**事後検査で品質担保**。

### 第4ラウンド — 自由比喩ユーモア
- 「人間＝金融銘柄」真顔比喩を1箇所入れる方針。
- B01「全ポイント防御振り」などは効いたが、B10で **「知識は未上場株式の高評価を活かし」型の文法破綻**が発生。
- 真剣類型では比喩抑制（C6/C7）を追加。

### 第5ラウンド — 型フレーズ集＋だ・である調
- 自由発明をやめ、`humor_phrases.json`（旧H01〜H05）から選択のみ。
- 文体を **だ・である調に正式統一**（C8追加）。C4で比喩も文法判定。
- 破綻率は下がったが、フレーズ自体のトーンは仮置き。

### 第6ラウンド — Yota作フレーズ（最終）
- H06〜H13（humor/serious レーン）に全面置換。旧H01〜H05は `archive` に退避。
- serious レーンは真剣類型でのみ使用可。glossary なし。
- 最終 **PASS 10/10**。注目フレーズ選定:
  - B01 → **H06**（日本銀行券にオールイン）
  - B02 → **H10**（マイナスEV／テーブルから降りる）
  - B10 → **H08**（バンクロール／ステーキング）
  - B05 → **H13**（ステークスを上げる）

## 本番組み込み時の注意

1. LLMは **localhost Ollama のみ**。クラウドAPIへのフォールバック禁止。  
2. フレーズ追加・差し替えは `humor_phrases.json` の `phrases` を編集する（コード変更不要）。  
3. 生成→検査→FAIL再生成のパイプラインをサイト組み込み時も踏襲する。  
4. 金額数値はコメントに書かせず、計算ロジック側の数値を正とする。
