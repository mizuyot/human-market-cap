# 人間時価総額 CALCULATOR

属性・資産・金融リテラシーから、人間時価総額をDCF風に算出するモバイル向けWebアプリです。

## v16 公開向け構成

- 学歴15区分、容姿5段階、職業30種
- 金融リテラシークイズ15セットからランダム5セットを出題
- クイズ正答・採点・時価総額計算はサーバー側で実行
- ブラウザには出題された問題だけを配信し、採点後に解説を返却
- Cloudflare D1へ匿名IDと最新スコアだけを保存
- ランキングは一人1レコード、上位1000件を維持
- APIの入力値検証、同一オリジン確認、短時間レート制限
- 年収・資産チャート、前回差分、X共有

## データの扱い

査定条件はデータベースへ保存しません。ランキングには端末生成の匿名ID、最新スコア、更新日時だけを保存します。クイズ回答とハッシュ化した不正防止情報は短時間で失効し、期限後に削除対象になります。

## ローカル開発

Node.js 22.13以上が必要です。

```bash
npm install
npm run db:generate
npm run dev
npm run build
npm test
```

永続データは `.openai/hosting.json` の論理バインディング `DB` を通じてD1へ保存されます。本番用のデータベース識別子や管理鍵をブラウザへ配置する必要はありません。
